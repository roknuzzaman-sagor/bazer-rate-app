# bazer-rate-app

A modern, responsive web application that helps people in Bangladesh check daily prices of essential products, explore market trends, and make informed shopping decisions.

## 🛠️ Technologies Used
- **Next.js** — React framework
- **React** — UI components
- **JavaScript** — Application logic
- **Tailwind CSS** — Responsive styling
- **daisyUI** — UI components and styling
- **Better Auth** — Authentication
- **REST API** — Product and market price data

## ✨ Key Features
1. 📊 **Daily Market Prices** — View today's prices of essential products.
2. 📈 **Price Trends** — Identify products with increasing or decreasing prices.
3. 🗂️ **Category Filtering** — Browse products by category.
4. 🔍 **Product Details** — Explore current prices and historical price comparisons.
5. 📱 **Responsive Design** — Works across mobile, tablet, and desktop devices.
6. 🔐 **Authentication** — Sign up, sign in, and manage user access.
7. 🎨 **Modern UI** — Clean interface with reusable components.
8. ⚡ **API Integration** — Fetch product and category data dynamically.

##  Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure your environment variables in `.env.local`.
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:3000` in your browser.

## ⚠️ Disclaimer
Displayed prices are indicative and may vary by location, market conditions, and time.
